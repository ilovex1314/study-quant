# study-quant

面向中国 A 股市场的量化学习项目。它先帮助学习者理解量化是什么、一个量化项目怎么做，再逐步进入数据、信号、回测、风控和编程落地。

本项目只用于学习与研究，不构成投资建议。

## 内容结构

- `docs/interactive-learning/overview.md`: 学习总览
- `docs/interactive-learning/day01.md`: 量化到底是什么
- `docs/interactive-learning/day02.md`: 从投资想法到策略报告
- `docs/interactive-learning/day03.md`: A 股市场规则与数据边界
- `docs/interactive-learning/day04.md`: 编程落地的最小架构
- `docs/interactive-learning/day05.md`: Python 时间序列入门
- `docs/interactive-learning/day06.md`: 第一张收益曲线
- `docs/interactive-learning/day07.md`: 第一个均线策略
- `docs/interactive-learning/day08.md`: 回测陷阱
- `docs/interactive-learning/day09.md`: 仓位与风险控制
- `docs/interactive-learning/day10.md`: ETF 轮动与组合思维
- `docs/interactive-learning/day11.md`: 策略研究报告
- `docs/interactive-learning/day12.md`: 模拟跟踪与学习闭环
- `apps/interactive-lessons`: React + TypeScript 互动学习应用
