# Day03 A 股市场规则如何影响量化策略

## Today Goal

理解中国 A 股市场的基础交易规则，以及这些规则为什么会改变策略设计、回测假设和编程实现。

今天结束后，你应该能列出 A 股量化策略必须考虑的市场约束清单。

## Why This Matters

很多海外量化教程默认 T+0、无涨跌停、数据质量较稳定、做空和融资工具更普遍。A 股有自己的交易制度和市场结构。如果直接照搬其他市场教程，回测结果会很容易失真。

## Core Concepts

### 市场规则约束

市场规则约束是交易所和监管规则对交易行为的限制。

它解决的问题是定义策略能不能执行。边界是：课程只讨论学习研究所需的基础规则，不替代券商和交易所最新规则。常见错误是在回测里假设当天买入当天卖出。

### 可交易性

可交易性是一个信号能否真实转换成交易。

它解决的问题是区分“纸面收益”和“可能成交”。边界是：日线回测无法精确模拟真实盘口。常见错误是忽略停牌、涨跌停、流动性和成交成本。

### 指数与 ETF

指数是市场表现的测量工具，ETF 是可以交易的基金产品。

它解决的问题是给学习者提供更稳定的研究对象。边界是：指数不能直接买卖，ETF 才是具体交易标的之一。常见错误是用指数回测收益，却忘记真实执行要通过 ETF 或组合。

## Underlying Architecture

建议画一张“A 股策略约束层”：

```text
策略信号
  -> 市场规则检查
  -> 标的可交易检查
  -> 成本和滑点假设
  -> 仓位限制
  -> 回测成交模拟
  -> 风险指标
```

模块职责：

- 规则检查：交易时间、T+1、涨跌幅、停牌。
- 可交易检查：成交额、流动性、是否可买卖。
- 成本假设：佣金、印花税、过户费、滑点。
- 仓位限制：单一标的、行业、现金比例。

## Data And Logic Flow

输入：策略生成的买卖信号。

处理：检查信号当天是否可执行、执行价格如何假设、是否受 T+1 和涨跌停影响。

状态：信号不等于成交，成交还需要经过市场约束。

输出：更接近真实的交易记录和资金曲线。

反馈：如果大部分信号难以成交，就要修改策略频率、标的池或交易规则。

## Key Technical Points

- A 股普通股票通常需要考虑 T+1 卖出约束。
- 涨跌幅限制会影响止损和追涨策略的成交假设。
- 停牌会导致持仓无法按计划退出。
- ETF 和指数适合作为入门研究对象，但指数和 ETF 不是同一个东西。
- 程序化交易受到监管规则约束，学习阶段应先聚焦研究和模拟，不急于自动下单。

## Production Example

策略信号：某 ETF 今日收盘价站上 20 日均线，明日买入。

真实研究时要补充：

- 用明日开盘价还是收盘价模拟买入？
- 是否加入手续费？
- 如果明日大幅跳空，是否仍然买入？
- 如果标的是股票而不是 ETF，是否存在涨跌停导致无法成交？

## Counterexample

错误做法：策略在当天收盘价计算信号，然后假设当天收盘价买入。

问题：这可能引入未来函数。真实情况下，你在收盘后才知道收盘价，不能再用同一个收盘价完成交易。
