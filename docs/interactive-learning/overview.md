# 量化学习总览

## 学习定位

这是一套面向工程实践的量化入门课程。它不从公式开始，而是先建立概论：量化到底是什么、一个普通投资想法如何变成策略、编程在量化流程中负责什么。

学习场景默认面向中国 A 股市场，强调低频到中频研究、ETF/指数/股票日线数据、风险控制和可复盘流程。本课程不提供任何具体投资建议。

## 核心心智模型

量化不是用代码预测股价，而是把投资想法变成可验证、可复盘、可约束的规则系统。

```text
量化 = 投资假设 + 明确规则 + 数据验证 + 风险约束 + 纪律执行
```

完整流程是：

```text
投资问题
  -> 策略假设
  -> 数据需求
  -> 数据清洗
  -> 信号生成
  -> 回测验证
  -> 风险评估
  -> 策略报告
  -> 模拟跟踪
  -> 是否实盘
```

## 学习路径

Day01 建立概论：理解量化是什么、不是什么。

Day02 建立项目流程：知道一个想法如何变成策略报告。

Day03 建立市场边界：理解 A 股规则如何影响策略。

Day04 建立编程架构：知道代码模块如何服务于数据、信号、回测和报告。

Day05 进入 Python 时间序列：理解行情数据、日期索引、复权价格、收益率和滚动窗口。

Day06 生成第一张收益曲线：把价格转成累计收益、波动率和最大回撤。

Day07 实现第一个均线策略：把趋势想法转成信号规则。

Day08 识别回测陷阱：未来函数、过拟合、成本、样本偏差和失败阶段。

Day09 建立仓位和风险控制：仓位上限、分散、回撤观察和再平衡。

Day10 学习 ETF 轮动与组合思维：标的池、打分、权重和调仓周期。

Day11 写策略研究报告：假设、数据、规则、表现、风险和下一步。

Day12 建立模拟跟踪闭环：策略日志、实时观察、偏差复盘和迭代决策。

## 验收标准

完成第一阶段后，学习者应该能：

1. 解释量化为什么不是简单预测股价。
2. 把一个模糊投资想法改写成可验证规则。
3. 画出量化项目从想法到报告的流程图。
4. 说出 A 股交易规则对策略的影响。
5. 设计一个最小代码架构，包含数据、信号、回测、指标和报告。
